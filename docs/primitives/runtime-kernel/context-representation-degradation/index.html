                Primitive：上下文表示降级

                Theme：运行内核 · 成熟度：Observed Pattern · 上下文压缩

                上下文表示降级把 media、blob、远程文件引用或其他高成本节点改写为更便宜且明确标注的模型可见表示，并说明原内容能否重新挂载。

                领域模型与契约

                要素 契约
                输入 rich Context node、MIME/type、估算成本、触发原因，以及可选的本地持久化目录或原 URI
                状态 降级策略、原节点身份、恢复 locator、临时资源生命周期和替换后的成本
                输出 文本 placeholder、caption、URI 或本地引用；若实现支持恢复，还包括可重新挂载原内容的 handle
                不变量 降级必须显式可见且确实降低成本；不能把 placeholder 冒充原内容；声称可恢复时 locator 必须对应仍可访问的对象
                边界 本 Primitive 不判断工具结果的时间保留优先级，不生成语义任务快照，也不拥有 compaction transaction 的提交与继续

                “表示变便宜”与“信息仍存在”是两件事。实现可以把字节移到模型上下文之外并留下可恢复引用，也可以永久丢弃附件只留下类型说明；页面必须把二者分开记录。

                显露差异的 Situation

                截图暂时不需要但稍后仍要检查

                当前 Turn 已从截图提取初步结论，预算压力要求移除图片。若 Harness 把 blob 写到 Session 作用域临时目录并留下路径，后续可以显式重新读取；若只留下“曾附加 image/png”，模型必须知道像素已经不可恢复，不能继续声称看得到图像细节。

                Provider 因大附件拒绝原请求

                Harness 需要重放同一用户请求，但原 media 已使 provider overflow。它可以把附件 part 改写成含 MIME 和文件名的文字，再告诉模型附件已移除；如果静默删掉 part，模型可能误判用户从未提供文件。

                远程文件 URI 在恢复时失效

                placeholder 保存了原 URI，但权限、签名或网络状态已经变化。URI 是 provenance，不是可用性保证；重新挂载前必须重新授权或读取，失败应作为新的 Observation 暴露。

                各 Harness 的实现

                Gemini CLI

                • 状态 / 事实类型：implemented + implemented
                • 谱系计数：Gemini 与 Qwen Code 的共同继承机制只计一个 Family。

                Gemini 的 BlobDegradationProcessor 将 inline base64 blob 写入按 Session 分隔的临时目录，再用包含 MIME、大小和路径的文本节点替换；远程 fileData 则保留 MIME 与原 URI。只有新表示估算成本更低时才替换，并通过 replacesId 记录来源。blob 持久化与文本替换

                OpenCode

                • 状态 / 事实类型：implemented + implemented
                • 谱系计数：独立于 Gemini/Qwen Family。

                OpenCode 在压缩输入中把用户附件和工具附件表示为带 MIME、文件名的文本标签，并把已清理的工具结果标成 [Old tool result content cleared]。压缩输入的便宜表示 当 overflow 需要 replay 原 user message 时，media file part 被改成相同类型的文字 placeholder；后续 synthetic continue 明确告知模型 media 已从上下文移除并建议用户缩小附件。overflow replay 与不可恢复提示

                限制与反例

                • 文件名、MIME 和 URI 不是图片内容的语义 caption；它们只保留表示来源。
                • 把 blob 写到临时目录不等于长期持久化，清理、迁移或换设备后 locator 可能失效。
                • UI 缩略图优化不属于模型上下文降级，除非它实际改变发送给模型的表示。
                • 对本来很小的 rich node 强制换成冗长 placeholder 可能增加 token，违反“确实降低成本”的不变量。
                • Gemini 与 Qwen 的同源 processor 只能作为一个 Family 的证据。

                相关 Primitive

                • 上下文压缩：可在事务准备阶段调用降级，但只拥有触发、提交与继续。
                • 工具输出保留：决定旧 Observation 是否保留；本页决定 rich content 用什么表示。
                • 语义上下文快照：由模型提炼任务状态，与确定性 placeholder 不同。
                • 上下文血缘：记录 degraded node 替换的原节点。
                • 状态持久化与恢复：决定临时资源和 locator 跨进程是否仍有效。
