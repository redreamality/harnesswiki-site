                运行内核

                导航：首页 · 机制地图 · 领域模型

                运行内核解释 Harness 怎样把外部输入推进为一系列可控制的模型决策与行动。这里按状态边界拆成十一个 Primitive，而不是用“Agent Loop”或“上下文管理”包住所有行为。

                flowchart LR
    Session["会话与运行拓扑"] --> Loop["Agent 循环与工作模式"]
    Instructions["指令发现与组装"] --> Context["模型可见 Context"]
    Memory["长期记忆"] --> Context
    Tools["工具与能力运行时"] --> Retention["工具输出保留"]
    Retention --> Context
    Degradation["上下文表示降级"] --> Context
    Snapshot["语义上下文快照"] --> Context
    Snapshot --> Lineage["上下文血缘"]
    Retention --> Lineage
    Degradation --> Lineage
    Context --> Compaction["上下文压缩事务"]
    Lineage --> Compaction
    Compaction --> Loop
    Routing["模型接入与路由"] --> Loop
    Loop --> Tools
    Tools --> Loop

                Primitive

                页面 独立状态或契约
                会话与运行拓扑 Session 身份、Turn/Step 边界、分支和终态
                Agent 循环与工作模式 状态转移、完成判定、角色或模式约束
                模型接入与路由 Provider 能力、模型选择、角色映射与换模
                上下文压缩 Compaction transaction 的触发、提交和继续边界
                工具输出保留 旧 Observation 的保留、裁剪、placeholder 与依赖缓存失效
                语义上下文快照 语义状态候选的生成、完整性与 stale 校验
                上下文表示降级 media/blob 等 rich node 的便宜表示与恢复 locator
                上下文血缘 replace/abstract 的来源身份、范围与审计关系
                长期记忆 跨 Session 的写入、scope、召回、更正与遗忘
                指令发现与组装 来源、作用域、优先级、信任和冲突
                工具与能力运行时 注册、schema、dispatch、结果规范化和撤销

                边界

                • 代码语义检索属于代码库智能；被选中的片段进入 Context Snapshot 后才属于运行内核。
                • 行动是否获准属于Action 授权；需要人类作答时由审批协调维护请求生命周期，并由审批者身份判定谁有权回答；效果能越过什么边界属于执行隔离。如何找到并调用工具才属于工具运行时。
                • Session 怎样持久化和恢复属于状态持久化与恢复；Session 内部的 Turn/Step 结构属于运行拓扑。
                • 外部客户端怎样控制 Session 属于控制平面。
                • Durable transcript 保存“发生过什么”；Context Snapshot 决定“下一次模型看到什么”；长期记忆选择“未来 Session 还要召回什么”。三者不可用一个 memory 字段代替。
                • 上下文压缩只协调事务；旧工具结果的保留、rich node 降级、语义摘要和变换血缘分别由对应原子 Primitive 拥有。
