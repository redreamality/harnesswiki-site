                  Primitive：工具输出保留

                  Theme：运行内核 · 成熟度：Proposed Abstraction · 上下文压缩

                  共识 Family：Gemini/Qwen、DeepSeek（2 票；需第三个独立实现后才能升级）

                  工具输出保留决定历史 Observation 中哪些工具结果继续以原文进入模型输入，哪些降为有标记的有损表示，以及替换后哪些依赖缓存必须失效。当前两组独立实现足以解释差异和边界，但尚未达到 Accepted Primitive 的三票门槛。

                  领域模型与契约

                  要素 契约
                  输入 当前模型可见的 tool call/result 对、结果大小、最近项预算、触发原因，以及由结果支撑的文件读取缓存等依赖
                  状态 保留阈值、低水位、最近项集合、call ID 到资源的映射、原结果与替换结果的关系
                  输出 原样保留的结果、显式 placeholder 或 head/middle/tail 裁剪结果，以及大小统计和需要失效的缓存键
                  不变量 不制造孤立 tool result；不能把 placeholder 当作仍可引用的原始字节；替换必须可识别且严格缩小；失败不能伪装成已清理
                  边界 本 Primitive 不生成语义摘要，不决定 compaction transaction 的提交或继续，也不负责工具本次执行时的结果规范化

                  这里的“保留”是模型输入投影策略，不是 durable transcript 的删除策略。实现可以在下一次请求中隐藏旧结果，同时继续保存原事件供恢复、回放或审计。

                  显露差异的 Situation

                  清理旧文件读取后再次编辑同一文件

                  模型曾读取文件全文，Harness 因预算压力把该结果替换成 placeholder。若读取缓存仍声称模型持有最新字节，后续 edit 可能基于已经不可见的内容执行。正确实现要么保留可引用结果，要么使相关 fast path 失效并要求重新读取。

                  大量命令日志挤占最近错误

                  一次构建产生多个超大输出，最后一个结果包含失败原因。按“最老先删”、按单结果 head/tail 裁剪和按最近 N 项保护会保留不同证据；无论采用哪种策略，都必须显式标出被移除的中段，而不能把拼接后的文字冒充完整输出。

                  各 Harness 的实现

                  Qwen Code

                  • 状态 / 事实类型：implemented + implemented
                  • 谱系计数：Gemini CLI 与 Qwen Code 的共同继承机制只计一个 Family；这里采用 Qwen 分化后的 file-cache 约束作为该 Family 的实现证据。

                  Qwen 的 microcompaction 对工具结果、顶层 media 和嵌套 media 分别计数。它按 call ID 找回文件路径；清掉 read/edit/write 结果时返回待失效路径，无法解析路径时要求更保守的缓存清理，避免模型只剩 placeholder 而缓存仍假定原字节可引用。工具分类与缓存依赖 · 低水位与最近项保护 · placeholder 与失效路径

                  DeepSeek Harness

                  • 状态 / 事实类型：implemented + implemented
                  • 谱系计数：独立于 Gemini/Qwen Family。

                  DeepSeek 的 ToolResultPruner 按 Unicode code point 计量，超过阈值时保留固定 head 和 tail，在中间插入 omission marker；非文本 block 保持相对顺序，输出必须小于原输入且不超过阈值。预算与裁剪不变量 它从稳定 surface 快照扫描结果，为每项追加带 surfaceOp: replace 和 sourceEventSeqs 的新事件，原事件仍在 append-only log 中。替换提交与原结果引用

                  限制与反例

                  • 字符阈值不是 token 阈值；不同 provider、语言和 rich block 的实际成本仍需单独计量。
                  • 保留最后 N 项不能证明保留了最重要的事实；它只是确定性的时间邻近策略。
                  • 只在 UI 折叠输出而仍把全文发送给模型，不属于本 Primitive 的模型上下文实现。
                  • 把整个 tool call 和 result 任意拆开会破坏 provider 协议；结果裁剪不能替代配对校验。
                  • Gemini 与 Qwen 的同源实现不能作为两票独立共识。

                  相关 Primitive

                  • 上下文压缩：拥有触发、提交与继续事务，可调用本 Primitive 先降低压力。
                  • 语义上下文快照：用模型提炼状态；本页的裁剪不声称理解语义。
                  • 上下文表示降级：处理 media、blob 等表示成本；工具结果中的 rich block 可能同时触及两者。
                  • 上下文血缘：记录原结果与替换结果的关系。
                  • 工具与能力运行时：拥有工具声明、dispatch 与本次结果规范化。
