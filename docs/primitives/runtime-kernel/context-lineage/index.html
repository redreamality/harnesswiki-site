                Primitive：上下文血缘

                Theme：运行内核 · 成熟度：Proposed Abstraction · 语义上下文快照

                上下文血缘记录一个模型可见节点替换、裁剪或抽象了哪些旧节点，使有损 Context 变换仍能解释来源、判断候选过期并支持审计。

                领域模型与契约

                要素 契约
                输入 原节点稳定身份或有序范围、变换类型、候选产物，以及所属 Session/transaction 身份
                状态 一对一 replace 边、多对一 abstract 边、surface 顺序、提交状态和原证据可用性
                输出 带 provenance 的新 Context node，或可查询的 replacement/abstraction 记录
                不变量 一对一替换与多对一摘要不得混写；引用必须指向本次选中的真实来源；位置顺序不能用数值 ID 大小猜测；失败事务不得留下“已提交”血缘
                边界 本 Primitive 不判断摘要是否真实，不保存代码来源 provenance，也不描述 parent/child Agent 或 fork Session 的身份关系

                血缘回答“这个表示从哪里来”，不回答“它是否正确”。原节点可以继续存在于 append-only log，也可以只剩受约束的引用；实现必须明确审计者还能否取得原内容。

                显露差异的 Situation

                异步 Snapshot 候选变成 stale

                候选声称抽象节点 A、B、C，但后台生成期间 B 已被另一 processor 替换。应用端可以用来源集合验证并拒绝候选；只有摘要文字而没有输入身份时，无法区分“仍适用”与“语言上看起来合理”。

                重复压缩后 surface 顺序不再等于 seq 顺序

                第一次压缩在旧位置插入一个新高 seq 的 summary，第二次又选择跨过它的可见范围。范围起点的 seq 可能大于终点；若用 [start, end] 数值区间代替 surface position 和显式成员集合，会错误遮蔽或漏掉节点。

                单个工具结果被确定性裁剪

                裁剪结果只替换一个 Observation，适合一对一 replacement；若错误记成“摘要了整个 Turn”，回放和 token accounting 都会把未变更节点算进损失范围。

                各 Harness 的实现

                Gemini CLI

                • 状态 / 事实类型：implemented + implemented
                • 谱系计数：与 Qwen Code 的共同继承机制只计一个 Family。

                Gemini Context Graph 的基础节点同时提供 replacesId 和 abstractsIds：前者描述 masking/degradation 的一对一来源，后者描述 synthetic summary 覆盖的 N 个节点。节点血缘类型 State snapshot 应用前用 consumedIds 校验当前 targets，提交后把同一集合写入 abstractsIds，再移除来源节点并在最早位置插入新节点。候选校验与血缘提交 · 同步路径

                DeepSeek Harness

                • 状态 / 事实类型：implemented + implemented，并有同仓版本化文档说明事务语义。
                • 谱系计数：独立于 Gemini/Qwen Family。

                DeepSeek 的 summary event 保存 shadowedRange、按 surface 顺序排列的 shadowedSeqs 和 token count；文档明确范围是位置 span，先前替换会使 start > end，成员集合才是权威来源。summary 血缘与非单调顺序 · 结果字段契约 对单个工具结果，pruner 追加 surfaceOp: replace、sourceEventSeqs: [seq] 和原/新 seq，保留 append-only 原事件供回放。一对一 replacement 实现

                限制与反例

                • provenance 完整不代表摘要 factual；血缘只能定位输入，不能证明输出忠实。
                • 只保留 token 前后值没有来源关系，不能回答哪些节点被替代。
                • Session fork 的 parentSessionId、subagent 的 parent identity 和 Git commit ancestry 是其他领域的 lineage，不能复用本页字段而忽略语义。
                • 若原始内容被物理删除，ID 只能证明曾有关联，不能提供 full-fidelity 审计；页面应明确 retention policy。
                • Gemini 与 Qwen 的同源 abstractsIds 不能作为两个独立实现计数。

                相关 Primitive

                • 语义上下文快照：产生多对一 abstraction candidate。
                • 工具输出保留：产生一对一裁剪或 placeholder replacement。
                • 上下文表示降级：把 rich node 替换为便宜表示。
                • 上下文压缩：在事务提交时原子发布新投影和对应血缘。
                • 会话与运行拓扑：拥有 Session、Turn、Step、branch 和 actor 身份，不属于 Context node lineage。
                • 重连投影：消费 durable evidence；有血缘不等于可以重放 Execution World。
