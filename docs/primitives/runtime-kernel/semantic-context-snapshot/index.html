Primitive：语义上下文快照

Theme：运行内核 · 成熟度：Proposed Abstraction · 上下文压缩

共识 Family：Gemini/Qwen、Pi（2 票；需第三个独立实现后才能升级）

语义上下文快照把一段历史提炼成可供后续模型请求继续工作的状态候选，并在提交前判断候选是否完整、有效且仍对应当前输入。Gemini 与 Qwen 的同源证据只能合计一票，因此当前仍缺第三组独立实现。

领域模型与契约

Section titled “领域模型与契约”
要素 契约
输入 待提炼的 Context 节点或消息、已有快照、当前目标与约束、预算，以及可选的文件操作或运行状态
状态 summary schema、生成模型与参数、候选版本、所消费输入的身份、失败计数和 usage
输出 标明为合成内容的 snapshot candidate，以及完整性、成本、覆盖输入和可提交性信息
不变量 空、截断或反而膨胀的候选不得冒充成功；异步候选只在输入仍有效时可用；摘要不能伪装成用户原话或外部事实
边界 本 Primitive 只拥有语义产物的生成与验证，不拥有预算触发、历史替换提交、继续策略或跨 Session 保留

Snapshot 是模型可见状态的有损表示，不是事实源。工作区文件、后台进程和工具结果可能在生成期间变化；后续行动仍需针对当前 Execution World 重新观察。

显露差异的 Situation

Section titled “显露差异的 Situation”

后台候选完成前历史再次变化

Section titled “后台候选完成前历史再次变化”

后台摘要开始后又发生两次编辑，并有旧工具输出被清理。候选即使语言上完整，也可能覆盖已不在活动图中的节点；实现需要用 consumed IDs、版本或等价校验拒绝 stale candidate，而不是按“最新完成时间”直接提交。

一个超大 Turn 跨越保留边界

Section titled “一个超大 Turn 跨越保留边界”

单个用户 Turn 包含多轮工具调用，长度已经超过保留预算。若切点落在 Turn 内，Snapshot 必须同时表达早期工作与仍保留的后半段，并保持 tool call/result 配对；简单复制最后一段对话会遗漏当前目标和已完成操作。

摘要调用返回不完整结构

Section titled “摘要调用返回不完整结构”

模型只返回 analysis、撞到输出上限，或生成的快照比原上下文更大。语法非空不等于产物有效；Harness 应保留旧投影、记录失败并限制无限重试。

各 Harness 的实现

Section titled “各 Harness 的实现”

Gemini CLI

Section titled “Gemini CLI”
  • 状态 / 事实类型：implemented + implemented
  • 谱系计数：与 Qwen Code 的共同继承机制只计一个 Family。

Gemini 的异步 processor 发布带 consumedIds 的 PROPOSED_SNAPSHOT；应用 processor 先确认这些 ID 仍在当前 targets 中，候选失效时不提交，并可退回同步生成。成功节点以 SNAPSHOT 类型和 abstractsIds 写入活动图。候选校验与应用 · 同步生成与覆盖集合

Pi

Section titled “Pi”
  • 状态 / 事实类型：implemented + documented
  • 谱系计数：独立于 Gemini/Qwen Family。

Pi 将旧消息、previous summary 与累计文件操作交给结构化 summarizer；普通压缩和 branch summarization 复用包含 Goal、Constraints、Progress、Decisions 与 Next Steps 的格式。产物连同 firstKeptEntryId、tokensBefore 和 usage 写入 CompactionEntry，后续上下文由 summary 与保留尾部重建。生成流程与快照入口 · 结构化摘要格式

Qwen Code

Section titled “Qwen Code”
  • 状态 / 事实类型：implemented + implemented
  • 谱系计数：只作为 Gemini/Qwen Family 内的分化证据，不增加独立实现票数。

Qwen 要求 side query 产生 <state_snapshot>，拒绝 strip 后为空、疑似撞输出上限、结构未闭合或压缩后 token 反而增加的结果；连续自动失败达到三次后 cheap gate 暂停重试，强制成功才重置。候选完整性检查 · 空结果与膨胀拒绝 · 失败熔断 固定恢复探针还观察到：已有 checkpoint 会在 resume 时成为 API history 起点，压缩后 tail 继续追加，压缩前原文不再进入模型投影。输入与断言 该探针验证快照消费，不验证摘要生成质量。

限制与反例

Section titled “限制与反例”
  • 摘要成功返回不等于内容正确；现有实现没有共享的 factuality 或 task-completion 指标。
  • 把最后 N 条消息拼接成新 prompt 是 retention，不是语义快照，除非存在明确的合成产物和有效性判断。
  • Snapshot 中“测试已通过”仍只是派生陈述，不能替代新的命令结果或 durable external evidence。
  • Branch summary、预算快照和跨 Session memory 可以使用相似文本格式，但触发、寿命与所有权不同。
  • Gemini 与 Qwen 的同源 state snapshot 不能机械计作两套独立设计。

相关 Primitive

Section titled “相关 Primitive”
  • 上下文压缩：决定何时开始事务、是否提交候选以及提交后如何继续。
  • 工具输出保留：在生成快照前可先清理无需语义理解的旧 Observation。
  • 上下文表示降级：降低 media/blob 的表示成本，不生成任务状态摘要。
  • 上下文血缘：说明 Snapshot 覆盖了哪些原节点。
  • 长期记忆：跨 Session 选择性保留；Snapshot 默认只服务当前 Session 的继续执行。
