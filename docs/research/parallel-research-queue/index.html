                  未决机制并行研究队列

                  导航：研究索引 · 研究方法 · 版本演进 · 机制地图

                  本轮于 2026-10-24 启动。十二个问题分为六组，每组独占一个上游的刷新操作和自己的输出文件。协调者负责共享索引、规则、验收、提交和发布。任务完成指本轮证据交付完成，不等于已经解决该机制的全部未知项。

                  认领与完成判据

                  组 问题 研究对象 本轮完成判据 状态
                  A 审批竞争与超时；断线回放接入实时流 Qwen Code 核对 vote/timer/close 的唯一终态，以及窗口淘汰和 replay/live 边界；实测范围与未测真实 transport 分开 published 首轮
                  B 取消后的效果静止；并发写入时的工作区快照 Mistral Vibe 核对 child、进程与 checkpoint 各自 owner；至少给出一个真实模块或入口的实验，或有证据的运行阻塞 published 首轮
                  C 崩溃后的副作用判定；异步压缩候选与语义保留 DeepSeek Harness 区分未知结果修复与副作用去重，核对候选失效条件；语义质量不以结构测试代替 published 新旧比较；新版压缩实验 blocked
                  D 暂停后的重新授权；扩展重载与授权延续 Stakpak Agent 核对 policy/workspace 变化、旧 Action 再执行，以及扩展能力激活/撤销路径 published 首轮；Skill 本地实测通过
                  E 完成证据新鲜度；工作认领与接管 Refact 核对 producer/verifier/owner 的版本绑定，以及重复 claim、晚到结果和 join published 首轮
                  F 长期记忆纠正与遗忘；隔离降级与进程所有权 Kilo Code 核对 scope、索引与删除传播，区分 worktree、后台进程和安全隔离边界 published 首轮

                  可核验的结果

                  六组均已交付底稿和版本记录，并取得本轮默认分支 SHA。协调者已重跑 Qwen、Mistral、Refact、Kilo 和 DeepSeek 的可运行探针；Stakpak 在独立 GNU host 工具链下也通过五组本地 Skill 实测。DeepSeek 经确认的代理连接成功刷新后，补了新版恢复与普通投影实测；新版压缩加载缺少依赖，仍只保留源码结论，不能混淆旧版压缩实验与当前源码。

                  已接收单元 本轮可核验结果 仍需实验
                  Qwen 12 组模块探针通过；ring 缺口后仍可能出现完成标记；六种审批竞争顺序只有一个终态 真实 HTTP/SSE 与 SDK resync，consensus 最后一票、跨重启
                  Mistral Windows 父子进程退出并停止写入；逐文件恢复保留成功项；并发写入可被覆盖 Unified 完整父子会话、其他进程后端、断电与崩溃一致性
                  Stakpak async 恢复采用源码证据；五组真实本地 Skill 发现、重读和失败回退实验通过 计数工具双恢复、跨身份/环境重新授权、完整 MCP 关闭与撤销
                  Refact 两 SHA 各六场景九断言通过；总评 MET 与单项 UNMET 矛盾仍解析为成功 真实 verifier 生成、文件变化后重新验收、跨进程 claim 和 merge
                  Kilo 八项记忆模块实测通过；linked worktree 共用记忆，精确 forget 不清除旧 digest 已注入 prompt 的失效、并发删除、真实 sandbox 与进程接管
                  DeepSeek 新 SHA 的真实外部写入、unknown 修复和普通投影重载通过；旧 SHA 另有异步候选与两次压缩实测 新版压缩模块依赖、完整 coordinator、真实模型摘要质量及并发恢复

                  本轮研究沿用以下已完成证据，避免重复把模块验证当成端到端验证：

                  • Qwen 控制面实验已经验证进程内 mediator 与 EventBus 的部分行为，未覆盖真实 transport、跨重启和所有淘汰/竞争路径。
                  • 恢复实验已经验证 Qwen 恢复投影和 DeepSeek 未知工具终态修复，不能判断真实外部副作用是否发生。
                  • Mistral 取消探针已经证明有界取消等待不保证 Task 静止，不能据此推断所有真实子进程的表现。

                  接收与下一轮

                  每组交付一份研究底稿、一份版本演进记录，以及实际执行时使用的可复现探针。表中 published 只表示本轮稿件随站点交付，blocked 限定对应刷新或实验，不掩盖已经取得的历史或静态证据。公开版本核对成功后才通知完成。下一轮优先处理上表的具体实验，不把首轮发布当作十二个问题全部解决。

                  后续跨 Harness 对比应挑不同 Family 的实现。同一上游中的两个入口、Fork 继承代码或同一个算法的多个测试，不增加独立设计票数。
