                DeepSeek Harness

                语料层级：Anchor Harness · 形态：Web / Headless / 可组合 runtime
                研究锚点：master@47f943859bef60e4160492346772ded9b24f765a · 快照日期：2026-08-17
                行为锚点：99f6f02fecdb7dff40c3fbc9470f5907c29f74ca · 实验日期：2026-08-19
                本地物化：99f6f02fecdb7dff40c3fbc9470f5907c29f74ca（2026-08-25）· 仅与行为锚点对齐；静态研究锚点仍漂移，见版本审计
                许可证：MIT · 状态：Developer Preview · 谱系：DeepSeek Harness

                DeepSeek Harness 把 append-only Session events、live Agent events、Plugin tree 与 capability provider/consumer 作为一等架构对象。它最适合检验：耐久事实、模型可见 Context 和正在运行的 actor 是否能真正分开。

                纳入理由与边界

                项目拥有完整 Step/Turn loop、事件化 Session、工具与 execution-world capability、插件生命周期、subagent 和 headless/Web 入口。虽然仍标记 developer preview，其固定源码和架构文档足以支撑机制研究；版本不稳定性会作为证据限制保留。

                自身领域模型

                flowchart LR
    Input["claimed input"] --> Turn["Turn: 0..n Steps"]
    Turn --> Step["Step: model request + tool calls"]
    Step --> Agent["live Agent"]
    Agent --> AE["agent/* lifecycle events"]
    Step --> SE["session/* durable events"]
    SE --> Log[("append-only Session log")]
    Log --> Projection["model-visible projection"]
    Agent --> Plugin["Plugin tree"]
    Plugin --> Cap["Capability provider / consumer"]
                • Step 明确定义为一次模型请求及其工具调用。
                • Turn 从输入被 claim 前开始，到没有待偿工作时结束，包含零个或多个 Step。
                • SessionEvent 是 append-only durable fact；任何模型可见输入应能从日志重建。
                • Agent 是 live actor，agent/* event 携带运行对象并服务拦截，不等同于 durable Session。
                • Capability 把 filesystem、subprocess、LSP、subagent 等 execution-world 能力与 consumer 解耦。

                已研究 Primitive

                Primitive 状态 DeepSeek 的实现取向
                会话与运行拓扑 implemented Turn/Step 有显式事件边界，Session 是 append-only log
                Agent 循环与工作模式 implemented 输入 claim、待偿工作与 Step events 驱动循环
                上下文压缩 implemented log 保持耐久，surface projection 可由 compaction 替换
                工具输出保留 implemented pruner 以 replace surface event 保留原 source event lineage，并按 head/tail 预算裁剪
                上下文血缘 implemented projection event 用 sourceEventSeqs 关联被替换的耐久事件
                工具与能力运行时 implemented capability provider/consumer 隔离 execution world
                代码库智能 implemented LSP 与 filesystem/subprocess provider 可共同迁移
                状态持久化与恢复 implemented resume/fork/transcript/telemetry 从同一事件源派生；未知工具终态显式合成，未知 required schema 拒绝恢复
                Action 授权 implemented per-session ApprovalPolicy 在 mediation 前决定 ask 或 never，并 fail closed
                审批协调 implemented request id、asked/decided event、answerer waterfall 与 cancel/unavailable outcome 分离
                审批者身份 alternative answerer 只处理自己拥有的 Agent request；终端用户 authentication 仍为 unknown
                Goal 证据协议 alternative revisioned Goal 拥有 durable terminal state，但没有已证实的独立 evidence verifier
                工作拓扑 unknown Goal continuity 已实现；通用 Work item dependency/claim graph 未定位
                Actor 委派 implemented capability provider 支持 one-shot/continuable child、follow-up、interrupt 与 disposal
                后台 Job 生命周期 implemented Job registry 提供 stable id、status、read/wait/kill 与 owner disposal
                扩展与生命周期 implemented Plugin tree、live hooks 与 capability binding
                耐久 Transcript implemented append-only Session event log 是 resume/fork/projection 的耐久事实源

                事件驱动时序

                sequenceDiagram
    participant I as Input Queue
    participant A as Live Agent
    participant P as Plugin Tree
    participant M as Model
    participant C as Capability
    participant S as Session Log

    I->>A: claim input / open Turn
    A->>S: turn/started
    loop each Step
        A->>P: agent lifecycle hook
        A->>M: projected Context
        M-->>A: response + tool calls
        A->>S: step/model events
        A->>C: capability request
        C-->>A: Observation
        A->>S: tool/session events
    end
    A->>S: turn/terminal

                设计取向

                • Event log 是事实，Context 是投影：压缩可以改变模型下一次看到什么，不覆盖已经发生的 Session events。
                • Live 与 durable 分离：Agent lifecycle hooks 可以携带运行对象，Session log 保持可序列化事实。
                • Capability seam 深于工具表：执行世界的一组能力可以整体替换，支持本地/远端 placement。
                • 工作与 actor 分开：goal、job、subagent 不共享一个过载 Task 对象。

                行为实测

                恢复边界行为实测复跑固定行为锚点自带的 keyless assembled-app snapshot。只有 durable tool/call、缺少 result 的 Session 在恢复时追加 TOOL_OUTCOME_UNKNOWN，旧 Step/Turn 以 interrupted 闭合，工具不会盲目重放；更高日志版本和未知 required event 都以退出码 1 拒绝恢复并保留 raw log 路径。该 observed 证据使用录制模型响应，覆盖真实 Loader、JSONL persistence 与 headless adapter，不等于实时模型黑盒。

                已知证据空白

                • developer preview 意味着事件 schema 和 plugin contract 可能快速变化，升级必须重新固定锚点。
                • 通用工作树 checkpoint/rollback、自动验证 policy 和多客户端控制面不在本轮确认范围。
                • capability 可替换不自动证明所有 provider 具有相同隔离或恢复语义。
